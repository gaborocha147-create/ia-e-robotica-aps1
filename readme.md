## APS 1 - IA e Robótica

Impacto real para um aspirador de pó mas a dimensão do mapa muda (2x2 até 30x30) com 
40% das células sujas.

É feita uma função que gera um mapa com a dimensão quadrada a partir das células e
40% delas estarão sujas.

posião inicial - (0,0)
posição final - (0,0)

Deve-se usar:
 - algoritmo de busca em largura 
 - algoritmo de busca em profundidade (determinar n ótimao)
 - profundidade iterativa

m para profundidade deve ser o mesmo para todas as dimensões no algoritmo de 
profunidade.
